# Standing instructions

Hard rules that apply to every post. Agents treat these as non-negotiable. Edit to taste —
these defaults are a reasonable starting point.

- **Honesty bar:** claim only what the evidence supports. If something wasn't tested, say so.
  Negative results are publishable.
- **De-identification:** no employer, client, product, internal handle, repo slug, or account
  id ever appears in public output.
