# Blog pipeline — manifest

Single source of truth for the backlog. One row per idea. Maintained by `/blog-pipeline`.
Edit by hand anytime — it's just a table.

## Legend
- **track** — `research` (essay/opinion) · `explainer` (first-principles teaching) · `thesis`
  (claim backed by an experiment/real numbers) · `build` (post documents something built).
- **stage** — `inbox` → `researched` → `experimenting`/`building` *(optional, by track)* →
  `drafting` → `critiqued` → `revised` → `illustrated` → `substack-draft` → `published`.
- **captured** — where/when the idea entered (`scout`, `inbox`, `session`, an external source).
- Only a human moves a row to `published`.
